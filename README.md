# 송용남 UI 디자이너 · 디자인 리드 포트폴리오

공개 주소: https://dmgpooh-lang.github.io/

GitHub Pages에서 빌드 없이 배포하는 정적 웹사이트입니다.

## 구성
- index.html: 개인 소개 메인, 프로젝트 목록, 업무 방식과 경력, 연락처
- employment.html: 고용조사분석시스템 프로젝트 상세
- styles.css / site.js: 반응형 디자인과 이메일 복사
- fluid-sculpture.webp: 승인한 시안을 바탕으로 생성한 곡선 조형 이미지
- employment-*.webp: 사용자 제공 Figma 프로젝트 화면

## 디자인
검정 배경, 형광 초록 포인트, 바람에 흐르는 곡선과 절제한 유리 질감을 사용합니다. 소개 문구는 HTML로 구현해 접근성과 반응형 레이아웃을 유지합니다. 움직임 줄이기 설정을 지원합니다.

## 자료
사용자가 제공한 경력 정보와 업무 방식, 기존 이력서 및 Figma 자료를 기반으로 작성했습니다. 확인되지 않은 프로젝트 기간, 기여율, 성과 수치는 포함하지 않았습니다.
