# 송용남 UI·UX 포트폴리오

공개 주소: https://dmgpooh-lang.github.io/

정적 HTML 포트폴리오입니다. GitHub Pages에서 빌드 없이 배포할 수 있습니다.

## 구성
- 경력 및 전문 분야 소개
- 고용조사분석시스템 사례 상세
- 연락처와 이메일 복사

## 로컬 확인
이 폴더에서 `python -m http.server 4173`을 실행한 뒤 http://localhost:4173 을 여세요.

## GitHub Pages
Settings → Pages → Deploy from a branch → main / root를 선택합니다.

## 자료
경력과 연락처는 사용자가 제공한 이력서, 프로젝트 화면은 사용자가 제공한 Figma 파일을 기준으로 작성했습니다. 프로젝트 기간·기여율·성과 수치는 근거가 없어 포함하지 않았습니다.
